⭐ GitHub-Projekt der Woche

agency-agents: Eine komplette KI-Agentur als Open-Source-Katalog

Quelle: GitHub

Das GitHub-Repository msitarzewski/agency-agents ist in dieser Woche auf Platz 3 der GitHub-Trends und hat über 145.000 Sterne erreicht. Das Projekt bietet einen Katalog von spezialisierten KI-Agent-Personas, die in Claude Code, Cursor, Codex, Gemini CLI und andere Coding-Tools installiert werden können.

Das Besondere: Die Agenten sind in Divisionen organisiert – von Frontend-Entwicklung über Produktmanagement bis hin zu Testing und DevOps. Jeder Agent hat eine spezifische Persönlichkeit, definierte Prozesse und nachgewiesene Ergebnisse. Ein Beispiel: Der »Jira Workflow Steward«-Agent erzwingt nachvollziehbare Commits, strukturierte PRs und release-sichere Branch-Strategien.

Die Divisionen umfassen Engineering, Product, Projektmanagement, Testing, DevOps, Security, Design und Growth. Das Projekt wird durch eine Desktop-App zum Stöbern und Aktualisieren der Agenten ergänzt.

Framework Laptop-Datenleck: 7.500 Kunden betroffen

Quelle: Wikimedia Commons

Diese Woche gab es gleich mehrere größere Sicherheitsvorfälle. 🔒 Sicherheitslücke einfach erklärt

CVE-2026-26956: vm2-Sandbox-Escape – Wie ein JavaScript-Trick Systeme kompromittieren kann

Quelle: Wikimedia Commons

Stell dir vor, du hast einen Raum mit dicken Gummibändern an den Wänden. Eigentlich solltest du dich darin nur vorsichtig bewegen, sonst schnellen die Bänder zurück. CVE-2026-26956 ist genau so ein Fall – nur mit Computer-Code.

Die Schwachstelle steckt in vm2, einer JavaScript-Sandbox, die normalerweise sicheren Code ausführt. Ein Angreifer kann durch geschickte Manipulation von Promises und Error-Handling aus der Sandbox ausbrechen und beliebigen Code auf dem Hostsystem ausführen. Betroffen sind alle vm2-Versionen vor 3.9.22.

Praktisch bedeutet das: Wer vm2 in einer Cloud-Umgebung oder einem API-Gateway einsetzt (z. B. für nutzereingereichte Code-Snippets), riskiert, dass Angreifer die vollständige Kontrolle über den Server übernehmen. Der Patch fixiert die Promise-Handhabung.

Eine weitere kritische Lücke ist CVE-2026-29000 in pac4j, einer Authentifizierungsbibliothek für Java-Apps. Hier können Angreifer durch manipulierte SAML-Tokens Authentifizierungschecks umgehen. Mindestens Cloud-Version von SonarQube und mehrere Apache-Projekte waren betroffen. Patches sind verfügbar.

❓ Wie funktioniert eigentlich…?

Wie funktioniert eigentlich… eine Sandbox in der Softwareentwicklung?

Quelle: Wikimedia Commons

Der Begriff »Sandbox« kommt ursprünglich vom Sandkasten: Ein abgegrenzter Bereich, in dem Kinder spielen können, ohne Schaden anzurichten. In der Softwareentwicklung funktioniert eine Sandbox genauso.

Eine Sandbox ist eine isolierte Umgebung, in der ein Programm ausgeführt wird, ohne auf das darunterliegende System zugreifen zu können. Man stelle sich eine Sandbox wie eine Plastikblase vor: Alles, was innerhalb der Blase passiert, bleibt auch in der Blase.

Technisch wird das durch verschiedene Mechanismen erreicht:

  • Betriebssystem-Ebene: Docker-Container, chroot, oder virtuelle Maschinen
  • Sprachebene: JavaScript-Sandboxen wie vm2, die den Zugriff auf systemnahe APIs blockieren
  • Hardware-Ebene: Intel SGX oder AMD SEV, die Speicherbereiche verschlüsseln

Warum braucht man das? Besonders wichtig ist die Sandbox für Cloud-Dienste, die nutzereingereichten Code ausführen – etwa Online-Editoren oder CI/CD-Pipelines. Ohne Sandbox könnte ein bösartiges Code-Snippet den gesamten Server übernehmen. Moderne Browser sandboxen ebenfalls jede Webseite in einem eigenen Prozess, sodass eine manipulierte Seite nicht auf andere Tabs oder das System zugreifen kann. Genau diese Technik war bei CVE-2026-26956 in vm2 ausgehebelt worden.

Docker 4.86.0: Neues CPO-Team und kritische Sicherheitsupdates

Quelle: Wikimedia Commons

Docker hat die Version 4.86.0 von Docker Desktop veröffentlicht. Das Update bringt neben neuen Funktionen vor allem wichtige Sicherheitspatches. Ein besonderer Fokus liegt auf der verbesserten Isolation von Containern unter macOS und Windows, nachdem mehrere Sicherheitsforscher potenzielle Privilege-Escalation-Pfade aufgezeigt hatten.

Organisatorisch gibt es ebenfalls Neuigkeiten: Docker hat einen neuen Chief Product Officer (CPO) ernannt, der die Produktstrategie für die nächste Generation von Container-Tools vorantreiben soll. Diese erlaubte Angreifern, durch manipulierte Container-Images aus dem Container auszubrechen. Administratoren wird dringend empfohlen, sowohl Docker Desktop als auch die Docker Engine zu aktualisieren.

Auch beim Thema Podman gibt es Bewegung: Red Hat hat Podman 6.2 mit verbesserter Kubernetes-Kompatibilität und nativer Unterstützung für sigstore-Container-Signierung veröffentlicht.

👻 Internet-Mythen

Gravity Blackout am 12. August: Warum die Schwerkraft nicht verschwinden wird

Quelle: Wikimedia Commons

Ein TikTok-Video, das im Januar 2026 viral ging, behauptete, dass am 12. August 2026 ein »Gravity Blackout« stattfinden würde – ein Zeitfenster von 3 Minuten, in dem die Schwerkraft aussetzen und alles schweben würde. Das Video wurde Millionen Mal geteilt und sorgte für zahlreiche besorgte Fragen bei Faktencheck-Organisationen.

Die gute Nachricht: Es wird keinen Gravity Blackout geben. Die Behauptung basiert auf einer Verwechslung mit der Perseiden-Meteoritennacht, die jedes Jahr um den 12. August stattfindet. Die Idee, dass ein Meteoritenschauer die Schwerkraft beeinflussen könnte, ist physikalisch absurd.

Die Erdanziehungskraft wird durch die Masse der Erde erzeugt – etwa 5,97 Trilliarden Tonnen Gestein und Metall. Ein paar kleine Meteoriten, die in der Atmosphäre verglühen, haben darauf genau so viel Einfluss wie ein Staubkorn auf einen Lastwagen. Der Gravity-Blackout-Mythos ist ein klassisches Beispiel für wissenschaftlich klingenden Unsinn, der sich auf sozialen Plattformen rasant verbreitet.

Faktencheck-Organisationen wie Snopes und FactCheck.org haben den Mythos bereits im Januar 2026 als falsch eingestuft. Der YouTuber und Physiker Dr. Alexander Blöchl erklärte in einem Video ausführlich, dass selbst bei einem Asteroideneinschlag die Gravitationswirkung auf Menschen vernachlässigbar wäre.

🌌 Neues aus dem Weltall

Nancy Grace Roman Telescope: Start am 30. August – Ein neues Fenster ins All

Quelle: NASA/Wikimedia Commons

Morgen, am 30. August 2026, soll das Nancy Grace Roman Space Telescope der NASA starten – eines der ambitioniertesten Weltraumteleskope seit dem James Webb Telescope. Die Trägerrakete steht bereits auf der Startrampe, die Nutzlastverkleidung wurde in dieser Woche integriert.

Das Roman-Teleskop hat eine Hauptaufgabe: die Erforschung Dunkler Energie und Dunkler Materie. Mit einem 2,4-Meter-Spiegel (gleiche Größe wie das Hubble-Teleskop) und einem Sichtfeld, das 100-mal größer ist als das von Hubble, wird es riesige Himmelsareale kartieren können.

Darüber hinaus ist das Teleskop mit einem hochmodernen Coronagraphen ausgestattet, der das direkte Abbilden von Exoplaneten ermöglicht – indem er das Licht des Muttersterns ausblendet. Wissenschaftler erhoffen sich davon die Entdeckung von erdähnlichen Planeten in bewohnbaren Zonen.

Aktuelle Ausgabe des Scientific American (September 2026) widmet dem Teleskop eine Titelgeschichte und listet zehn kosmische Entdeckungen auf, die Wissenschaftler vom Roman Telescope erwarten – darunter die präziseste Karte der Dunklen Materie, Milliarden von Galaxien und die erste vollständige Durchmusterung des inneren Sonnensystems nach Asteroiden.

Parallel dazu wurde am 28. August eine totale Mondfinsternis (»Blood Moon«) beobachtet, die in weiten Teilen der Welt sichtbar war.

📊 Neue Studie

Studie: Höhere Fluoridwerte im Trinkwasser während Schwangerschaft mit kognitiven Unterschieden bei Kindern verbunden

Quelle: Wikimedia Commons

Eine neue, vom US-amerikanischen National Institutes of Health (NIH) finanzierte Studie hat einen Zusammenhang zwischen Fluoridkonzentrationen im öffentlichen Trinkwasser während der Schwangerschaft und den kognitiven Fähigkeiten von Kindern gefunden.

Die im American Journal of Epidemiology veröffentlichte Studie der Columbia University Mailman School of Public Health untersuchte den Zusammenhang zwischen pränataler Fluoridexposition über das Trinkwasser und den Fluid Cognition Scores (fluide Intelligenz –also Problemlösungsfähigkeit und logisches Denken) bei Kindern. Die Forscher fanden, dass höhere Fluoridwerte mit niedrigeren kognitiven Testergebnissen assoziiert waren.

Die Studie ist bedeutsam, da sie zu einer wachsenden Zahl von Forschungsergebnissen beiträgt, die mögliche Auswirkungen von Fluorid auf die neurologische Entwicklung untersuchen. Die Weltgesundheitsorganisation (WHO) empfiehlt einen Grenzwert von maximal 1,5 mg/L. Die Debatte um Trinkwasserfluoridierung ist in den USA besonders relevant, wo etwa 73 % der öffentlichen Wassersysteme Fluorid zur Kariesprävention zusetzen.

Die Autoren betonen, dass weitere Forschung nötig ist, bevor Richtlinien geändert werden sollten. Karies-Prävention durch Fluorid bleibt ein wichtiges öffentliches Gesundheitsziel.

📊 Neue Studie

Neue Purdue-Forschung verbessert Luftqualitätsvorhersagen durch Aerosol-Verständnis

Quelle: Wikimedia Commons

Forschende der Purdue University haben einen Durchbruch bei der Vorhersage der Luftqualität erzielt. Ihre in den Proceedings of the National Academy of Sciences veröffentlichte Studie zeigt, wie die Wechselwirkungen zwischen benachbarten Molekülen in Aerosolgemischen die Verdunstungsraten beeinflussen.

Bisherige Modelle gingen oft von vereinfachten Annahmen aus – etwa, dass jede Molekülsorte unabhängig von den anderen verdunstet. Das Purdue-Team entdeckte jedoch, dass Nachbarmoleküle die Verdunstung erheblich beeinflussen. Dieses Verständnis könnte zu deutlich genaueren Luftqualitätsprognosen führen, was besonders in stark verschmutzten Regionen wie Indien und China wichtig ist.

Feinstaub-Aerosole (PM2,5) sind für Millionen vorzeitige Todesfälle pro Jahr verantwortlich. Genauere Modelle helfen nicht nur bei der Vorhersage von Smog-Episoden, sondern auch beim Verständnis, wie sich Waldbrandrauch ausbreitet – ein immer drängenderes Problem angesichts zunehmender Waldbrände weltweit.

🔬 Deep Dive

Deep Dive: KI-Agent-Ökosysteme – Wie spezialisierte Agenten die Softwareentwicklung revolutionieren

Quelle: Wikimedia Commons

🎬 HoodInformatik auf YouTube · HoodInformatik

Die Softwareentwicklung durchläuft einen fundamentalen Wandel. Während Large Language Models (LLMs) wie GPT-5.6 und Claude Opus 5 immer leistungsfähiger werden, entsteht parallel ein neuer Trend: spezialisierte KI-Agenten, die in Ökosystemen zusammenarbeiten.

Projekte wie msitarzewski/agency-agents (145.000+ Sterne auf GitHub) zeigen deutlich, wohin die Reise geht. Statt einem einzigen Allzweck-KI-Assistenten setzen Entwickler zunehmend auf spezialisierte Agenten, die jeweils eine klar definierte Aufgabe übernehmen: Ein Agent schreibt den Code, ein anderer testet ihn, ein dritter optimiert die Performance, ein vierter prüft die Sicherheit.

Diese Spezialisierung hat handfeste Vorteile:

1. Qualität: Spezialisierte Agenten liefern in ihrem Bereich bessere Ergebnisse als Generalisten

2. Überprüfbarkeit: Jeder Agent kann isoliert getestet und auditiert werden

3. Austauschbarkeit: Einzelne Agenten können durch bessere Versionen ersetzt werden, ohne das Gesamtsystem zu ändern

4. Skalierbarkeit: Teams können zusätzliche Agenten hinzufügen, ohne den Arbeitsablauf neu zu strukturieren

Die Agenten kommunizieren über standardisierte Schnittstellen. Claude Code, Cursor, Codex und Gemini CLI haben alle begonnen, solche Agent-Kataloge zu unterstützen. Auch Google und OpenAI verfolgen diesen Ansatz mit ihren »Skills«-Projekten (google/skills, openai/skills).

Doch es gibt auch Herausforderungen. Die Koordination mehrerer Agenten ist komplex – ähnlich wie bei menschlichen Teams braucht es klare Zuständigkeiten und Kommunikationsprotokolle. Das Projekt PrimeIntellect/prime-agent löst dies mit einem rekursiven Ansatz: Ein Agent kann Sub-Agenten spawnen, die dann eigenständig arbeiten und Ergebnisse zurückmelden.

Sicherheit ist ein weiteres Thema: Je mehr Agenten in der Pipeline arbeiten, desto größer die Angriffsfläche. Jeder Agent könnte potenziell manipuliert werden. Hier kommen Techniken wie Sandboxing (siehe CVE-2026-26956), signierte Agent-Manifeste und rollenbasierte Zugriffskontrollen ins Spiel.

Die nächste Stufe dieser Entwicklung wird die Integration von Spezial-Hardware sein. Unternehmen wie Microsoft und Apple arbeiten an KI-Coprozessoren – Chips, die speziell für das Ausführen von Agenten-Workloads optimiert sind und deutlich energieeffizienter arbeiten als klassische CPUs oder GPUs.

Der Trend ist klar: Die Zukunft der Softwareentwicklung wird nicht von einem einzelnen Super-LLM bestimmt, sondern von Ökosystemen spezialisierter Agenten, die in orchestrierter Zusammenarbeit arbeiten – ähnlich wie ein gut funktionierendes menschliches Team aus Frontend-, Backend- und DevOps-Experten nur effizienter und schneller.
