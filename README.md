## 📰 Über Bit & Byte

Bit & Byte ist deine wöchentliche Dosis Nerdy-Wissen. Keine Fake News, nur recherchierte Artikel mit Quellenangaben. Jede Ausgabe erscheint als **PDF** und wird auf dieser GitHub-Pages-Seite mit allen Quellen veröffentlicht.

## ⚙️ Automatisierung

Die Zeitung wird automatisch jeden Samstag um 8:00 Uhr generiert durch:
- **Deep-Research-Pipeline** → Web-Recherche mit Quellenprüfung
- **Content-Generator** → Artikel-Erstellung aus den Recherchen
- **PDF-Generator** → fpdf2-basierte PDF-Erzeugung
- **GitHub-Pages-Publisher** → Upload der Artikel mit Quellen
